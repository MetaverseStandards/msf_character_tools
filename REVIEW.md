# Reference implementation review

Original documentation CC-BY-SA-4.0.

The engineering, math adversary and SDK maintenance roles were applied in one implementation process. Review here means implementation self-review and concrete consumer/native peer feedback; it does not imply three independent human reviewers or standards adoption.

## Actual evidence

- 30 stdlib public API/CLI tests pass on Python3.12.15 and Python3.11.17, including an installed wheel exercised outside the checkout.
- Deterministic pack/CSV/coverage goldens and thin check command pass. Fixture generation uses separate axis equations and is reproducible.
- Original shared combined fixture covers two instances, four nonzero influences, signed/>1 relative morph defaults and authored/intermediate animation times.
- Independently authored consumer combined fixture agrees at nine samples: observed maximum component error8.2584e-8m, RMS2.2237e-8m, within its1e-5m tolerance.
- Consumer teams executed typed profile mappings, structural sidecars, tracking failures and separate real host tests. Read their own evidence before asserting host acceptance.
- Native pilot numerical/ownership agreement has separate native CTest evidence; reference acceptance alone is not a native build result.

## Defects found and fixed

1. Unbounded tiny zero-backed accessor count: add explicit component/object/resource budgets before allocation, including sparse paths.
2. Sparse sidecar resource completeness: include indices, values and base buffer hashes; corruption tests.
3. Coverage too narrow: retain full evidence including unused/unresolved sources; profile metadata/disposition/quality partitions and totals.
4. Extra outputs missed by manifest: scan owned common generation directory and fail unlisted entries.
5. CLI output alias could overwrite source: preflight resolved paths, hardlinks and symlink leaf outputs against authoring/assets/resources before replacement; actual negative subprocess tests leave input bytes unchanged.
6. Temporary directory platform symlink prefix: resolve output parents, keep explicit symlink leaf refusal.
7. Unknown required animation extension rejected too early: inventory extension targets, gate requested evaluation.
8. Native/reference acceptance mismatch: align skin weight sum tolerance1e-6 without normalization.
9. Inspection missed binary animation semantics: validate available core channel type/count/times/rotation keys; keep unavailable external inventory.
10. Hierarchy cycle validation repeated ancestor walks: use a completed-node set to bound traversal across all chains.

11. Fragment discovery could include virtualenv/CI hidden checkouts: prune generated/hidden files and directories before traversal; real fake-.venv/.git/.ci-tools tests.

## Remaining gates

The reference supports positions with relative Basis morphs/four influence LBS and one explicit core clip. Non-position geometry, eight influences, DQS, compressed semantics, unsupported required extensions, simultaneous clips and embedded asset rewriting remain explicit unsupported capabilities. Resource limits may reject otherwise valid large assets.

Production artist/contact acceptance, general provider calibration, external publication ownership, packaging platforms and performance requirements remain separate gates. Scalar mapping quality describes a declared operation under assumptions. No universal fidelity, community adoption, security against concurrently hostile filesystem writers or multi-file transaction guarantee is claimed.
