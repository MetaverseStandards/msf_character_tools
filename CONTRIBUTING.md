# Contributing

Original documentation: CC-BY-SA-4.0.

Use Python3.11+ and the standard library for the reference. Open a change with a concrete input/output description, license/provenance for new data, and the checks actually run. Keep signal semantics/calibration explicit; unresolved evidence may remain inventoried. New dependencies require a measured need and license review.

Before a change is accepted:

1. Run reference tests and generated byte checks on Python3.11 and3.12.
2. Add independently calculated expectations for changes in transforms/operators/curves. Do not generate mathematical expected values by calling the implementation being tested.
3. Review malformed input behavior, fail-closed Results, unchanged asset bytes, sidecar hashes and output aliases.
4. Update schemas/reference for wire changes; incompatible contracts require version/migration notes and compatibility fixtures.
5. Preserve original licenses and source attributions. Include public source revision/digest/locator for imported claims.
6. Record remaining gates honestly, including real host/native execution and visual/contact review where applicable.

Use existing repository review facilities when a publisher provides them. No external community channels or named human maintainers are implied by this document. Reversible local reference changes can be reviewed before publication; release and remote ownership follow repository governance.
